# What was implemented in v4.1

Implemented: selected A–E/G/H semantic guards, tightened/new schemas, generated linked examples, regression tests, explicit callable allowlist, parsed raw-form coverage verification, full sample dependencies, complete record-decision accounting, exact-revision review/use/export records, and a local no-send idempotent preview exporter.

New ledger source families are schema-defined and have reference examples. Their real collectors/extractors are not added. Compound rules 33–40, case-study quality ranking, embeddings/indexes, new source quotes/comparison copy renderers, scorecards and playbook discovery remain implementation work. The ledger’s unprovided Automation Playbooks tab has not been invented.

The fixture preserves broad collection independent of signal activation. Its two run records demonstrate an ingest/evaluate boundary; they are not a general scheduler. Authenticated principal resolution, live source approvals, database persistence, concurrency, provider operations and delivery remain absent.

Production is disabled. First close the explicitly deferred F/E07 authorization gap, then implement and test the selected runtime boundary. Schema/fixture checks are necessary but not production certification.
